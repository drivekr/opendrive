# raw/sources

근거의 원천. 외부 자료에서 확인한 사실과 출처를 사람이 소유하는 불변 기록으로 보존한다.
LLM은 이 근거를 읽고 `wiki/`의 해석을 수정한다. 공개 자료를 새로 발견하면 에이전트도 새 수집기록을 추가할 수 있다.

## Rules

- 새 자료는 **수집일** 기준 `YYYY-MM-DD-slug.md` 파일로 추가한다. 예: `2026-10-04-molit-r171.md`.
- 자료의 발표일·사건일은 본문에 별도로 기록한다. 연·월만 알면 그 정밀도만 쓰고, 모르는 날짜는 `Unknown`으로 남긴다. 기존 사건일 기반 파일명은 보존한다.
- 내용은 출처에 명시된 사실·짧은 발췌·출처 URL·확인 범위만 둔다. 가설·병목 해석·비교·측정 기준·다음 행동은 `wiki/`에 둔다.
- 기존 근거 파일은 수정·이동·삭제하지 않는다. 정정은 새 사실과 출처를 담은 파일로 추가하고, 이전 기록과의 관계는 위키에서 설명한다.
- 원문을 직접 확인했는지, 검색 색인만 확인했는지, 언론을 통해 인용한 것인지 구분한다. 예정·제안·완료도 출처가 말하는 수준 그대로 기록한다.
- 날짜·수치가 없으면 비워둔다 (`Unknown`, `Pending`). 추측 금지.
- 우선순위: 법령 > 정부 문서 > 국회 자료 > UNECE/WP.29 문서 > 언론.
- URL에 트래커(`utm_source` 등)를 붙이지 않는다.

## Flow

```text
raw/sources/  (외부 근거 보존, 사람 소유, 새 기록만 추가)
    ↓ ingest (에이전트)
wiki/         (LLM이 수정하는 정리·해석·병목·행동)
    ↓ render
landing page  (같은 근거의 다른 View)
```

수집기록을 위키에 반영한 뒤 `wiki/log.md`에 기록한다.
이 README는 수정 가능한 운영 안내이며 불변 근거 파일에 포함되지 않는다.
