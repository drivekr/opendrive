# 국내 Tesla FSD 적용 현황 (79.3% 불가)

- 2026-09-15 보도, 카이즈유데이터연구소 카차트 (2026년 8월 기준).
- 국내 운행 테슬라 누적 229,311대 중 FSD 사용 불가 181,853대 (79.3%). 사용 가능 약 21%.
- Model Y 사용 가능 9.6%. 2024–2026년형 전체 미지원. Model Y는 전체의 70%, 해당 3개 연형 합산 124,666대.
- Model 3 사용 가능 40.1% (미국산 롱레인지·퍼포먼스 견인). Model S·X 94.1% (단종, 비중 작음).
- 차봇모빌리티 2026-02 조사 (신차 예정자 450명): 고도 자율주행 추가 비용 지급 의사 76.5%.
