# FSD 무단 활성화 85건 공개 (박용갑 의원)

- 2026-05-04 보도. 국회 국토교통위원회 더불어민주당 박용갑 의원실 자료.
- 2026년 4월 28일 기준 FSD 무단 활성화 시도 85건 집계.
- 국내 합법 FSD는 미국산 Model S·X·사이버트럭만. 전체 등록 180,684대 중 4,292대 (2.4%). Model X 2,708 / Model S 1,193 / 사이버트럭 391.
- 한미 FTA로 미국산은 국내 인증 면제, 중국산은 안전기준 인증 미획득.
- 무단 활성화는 자동차관리법 위반 (안전 운행 영향 소프트웨어 임의 변경). 2년 이하 징역 또는 2천만원 이하 벌금.
- 국토부 수사 의뢰 + 테슬라코리아 소프트웨어 업데이트로 대응. 개인정보보호법상 소유자 특정 불가.
- 박용갑: "수사 의뢰나 원격 차단 같은 사후 대응만으로는 한계. 제도 개선 서둘러야." 관련 법안 발의 예정 언급.
